# KentBildir Mobile

KentBildir'in Expo, React Native ve TypeScript ile geliştirilen mobil uygulaması.

## Başlatma

```bash
cd mobile
npm install
npx expo start
```

Expo Go ile terminaldeki QR kodu okutabilir veya terminalden `i` (iOS), `a` (Android), `w` (web) tuşlarını kullanabilirsiniz.

## Kontroller

```bash
npm run lint
npx tsc --noEmit
npx expo-doctor
```

M1 yalnızca yerel mobil akışı ve mock verileri içerir; backend, gerçek AI ve gerçek konum entegrasyonu kapsam dışıdır.
